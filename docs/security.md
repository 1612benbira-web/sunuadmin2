# Sécurité et contrôle d'accès

**En place** : mots de passe bcrypt (coût 12) ; cookie HttpOnly, SameSite=lax, Secure en production ; JWT 8 h révocable (`tokenVersion` : déconnexion, changement de mot de passe) ; compte désactivé refusé immédiatement ; en-tête anti-CSRF sur les écritures ; CORS restreint à `CLIENT_ORIGIN` ; Helmet ; limitation de débit sur `/auth` ; validation Zod ; contrôle d'accès par rôle et par ressource (un dossier ou document d'autrui répond 404) ; transitions de statut vérifiées côté serveur ; fichiers : types vérifiés sur la signature, 4 Mo max, nom généré par le serveur, stockage hors dossier public, téléchargement après autorisation et journalisé ; journal d'audit des opérations sensibles ; aucun compte privilégié créé automatiquement.

**Limites connues, à traiter avant toute mise en ligne** : pas d'analyse antivirus (interface de stockage prête) ; stockage local des fichiers ; HTTPS et reverse proxy à configurer ; limitation de débit seulement sur `/auth` ; pas de verrouillage de compte ni d'authentification à deux facteurs ; pas de réinitialisation de mot de passe par e-mail ; sauvegardes à planifier ; pas d'audit de sécurité indépendant ; politique de conservation et d'anonymisation des données personnelles à définir.
